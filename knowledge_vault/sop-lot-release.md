A lot may be released only after QA review is complete and the lot status is AVAILABLE. The release decision belongs to a reviewer.

Release requests must cite the lot ID and the protocol reference from the lot record. A release request for a lot with no protocol reference is refused and the lot is quarantined instead; see [[sop-quarantine]].

Lots that are QUARANTINED or ON_HOLD cannot be released until the hold or quarantine is closed by a reviewer.
